# Annan CGM som laddar upp till Nightscout

Använd det här alternativet om du har någon annan CGM inställd som **bara** kan skicka dina BG-data till [Nightscout](https://nightscout.github.io/).

```{important}
Den här datakällan fungerar inte när du är offline, när du har nätverksproblem eller när din Nightscout-sida ligger nere. Använd med försiktighet.
```

-   Ställ in **NSClientV3** (**Konfiguration → Kommunikation**) med uppgifterna om din Nightscout-sida.
-   Välj NSClient BG i [**Konfiguration → BG-källa**](#Config-Builder-bg-source).
