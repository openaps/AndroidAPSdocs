# Other CGM uploaded to Nightscout

Use this option if you have any other CGM set up that can send your BG data **only** to [Nightscout](https://nightscout.github.io/).

```{important}
This data source will not work when you are offline, when you experience network issues or when your Nightscout site is down. Usala con cautela.
```

-   Configura **NSClientV3** (**Configurazione → Comunicazione**) con i dati del tuo sito Nightscout.
-   Seleziona BG NSClient in [**Configurazione → Sorgente Glicemia**](#Config-Builder-bg-source).
