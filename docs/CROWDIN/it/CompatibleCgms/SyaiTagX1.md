# Syai X1


## Usare X1 con l'app Syai Tag

-   Installa l'apk da <https://play.google.com/store/apps/details?id=com.syai.tag>.

-   Avviare il sensore X1

- Seleziona **Syai/Ottai** in [**Configurazione → Sorgente Glicemia**](#Config-Builder-bg-source).

Attiva la trasmissione (broadcast) nell'app Syai:

1. Seleziona Profile
2. Syai Health Ecosystem
3. Tocca Connect Now with AAPS e accetta l'accordo sul trasferimento dei dati a terze parti
4. Enable share data with AAPS
