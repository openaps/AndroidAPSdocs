# Alt CGM încărcat în Nightscout

Use this option if you have any other CGM set up that can send your BG data **only** to [Nightscout](https://nightscout.github.io/).

```{important}
Această sursă de date nu va funcționa atunci când sunteți offline, când întâmpinați probleme de rețea sau când instanța de Nightscout este căzut. Utilizați cu prudență.
```

-   Configurați **NSClientV3** (**Configurație → Comunicare**) cu informațiile site-ului dumneavoastră Nightscout.
-   Selectați Glicemie NSClient în [**Configurație → Sursă glicemie**](#Config-Builder-bg-source).
