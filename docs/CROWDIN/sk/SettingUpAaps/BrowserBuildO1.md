# Možnosť 1 – Vygenerujte nové úložisko kľúčov

```{note}
Táto stránka je súčasťou časti [Krok 2 – Vytvorte si podpisové úložisko kľúčov](BrowserBuildKeystore.md) návodu [Zostavenie v prehliadači](BrowserBuild.md). Make sure you have read the [Option 1 vs Option 2 decision](#aaps-ci-preparation).
```

Možnosť 1 vám vygeneruje úplne nové podpisové úložisko kľúčov. Je vhodná pre nových používateľov, pre tých, ktorí nemajú súbor JKS, alebo pre tých, ktorí zabudli heslo alebo alias.

## Vyberte svoje zariadenie

```{tip}
Zostavujete z **telefónu s Androidom**? Použite radšej [AAPS Builder](BrowserBuildAapsBuilder.md): nepotrebuje prípravný súbor.
```

Postupujte podľa stránky pre zariadenie, z ktorého zostavujete:

- **[Počítač](BrowserBuildO1Computer.md)** – Windows, Mac alebo Linux.
- **[iPhone / iPad](BrowserBuildO1iPhone.md)**.

```{tip}
Zariadenie môžete kedykoľvek zmeniť – stačí otvoriť príslušnú stránku.
```
