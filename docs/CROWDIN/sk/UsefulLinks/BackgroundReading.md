# Užitočné zdroje na prečítanie pred začatím

Skôr než si zostavíte svoj systém, budete musieť veľa čítať, aby ste pochopili, ako všetko funguje, a aby ste z neho dostali čo najviac. Pripravili sme zoznam miest, kde môžete začať a kde snáď nájdete odpovede na mnohé svoje otázky.
