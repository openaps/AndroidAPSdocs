# שינוי השפה והגרסה

התיעוד שאתם קוראים כעת זמין בכמה שפות, והוא מתאים לגרסה מסוימת של **AAPS**. ניתן לשנות את השפה ואת הגרסה מהתפריט שבפינה התחתונה של המסך.

```{note}
יש ללחוץ על הסרגל שבפינה התחתונה של המסך כדי לפתוח את תפריט בחירת השפה והגרסה.
```

![Open language menu](../images/documentation_language_menu.png)

## שינוי שפה

בתפריט יש לבחור את השפה שבה רוצים לקרוא את התיעוד.

אתם מוזמנים להצטרף למתרגמים ולמגיהים ב-[Crowdin](https://crowdin.com/project/androidapsdocs) ולעזור לתרגם את התיעוד לשפה שלכם.

## Change version

הגרסה הנוכחית מוצגת בפינה התחתונה של המסך. כדי לעבור לגרסה אחרת, יש ללחוץ על הגרסה הנוכחית ולבחור את הגרסה הרצויה.

```{warning}
בעת שינוי השפה ו/או הגרסה, ייתכן שתופיע השגיאה 404 - הדף לא נמצא, אם הדף אינו קיים בשפה או בגרסה שנבחרו. This will frequently happen when switching version but should not happen when changing language: the page will show in English if not translated yet.
```
