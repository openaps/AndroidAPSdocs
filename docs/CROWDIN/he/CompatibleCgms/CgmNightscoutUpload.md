# CGM אחר שמעלה נתונים ל-Nightscout

השתמשו באפשרות זו אם מוגדר אצלכם CGM אחר שיכול לשלוח את נתוני הסוכר **רק** אל [Nightscout](https://nightscout.github.io/).

```{important}
This data source will not work when you are offline, when you experience network issues or when your Nightscout site is down. Use with caution.
```

-   הגדירו את **NSClientV3** (**הגדרות תצורה → תקשורת**) עם פרטי אתר ה-Nightscout שלכם.
-   בחרו "נתוני סוכר מ-NSClient" (NSClient BG) ב-[**הגדרות תצורה → מקור ערכי הסוכר**](#Config-Builder-bg-source).
