# Handig om te lezen voordat je begint

Voordat je begint met bouwen, heb je nog wat leeswerk te doen om te begrijpen hoe alles werkt zodat je het maximale eruit kunt halen. We hebben een lijst gemaakt van plekken waar je kunt beginnen. Hopelijk vind je daar antwoord op veel van je vragen.
