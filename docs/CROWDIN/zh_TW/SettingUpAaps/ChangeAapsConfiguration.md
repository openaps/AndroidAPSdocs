# Making changes to your AAPS configuration

完成**[設置嚮導](../SettingUpAaps/SetupWizard.md)**後，如果你只想更改 AAPS 的部分設定，就不需要再次執行整個嚮導。

您可以透過三種方式變更 **AAPS** 的組態。選擇哪種方式，取決於您覺得哪種方式最方便或最符合個人偏好，因為這三種方式都會設定相同的項目。

如下所示：

1. **組態**畫面，
2. **設定**畫面，或
3. 從**組態**中的分類開啟外掛的**設定**。

在這裡我們解釋哪個選項對每種情況最方便：

## 設定

開啟主畫面左上角的**選單**（☰），然後選擇**組態**：

![從左上角的選單開啟組態](../images/v4/Configuration/configuration_menu.png)

**組態**用來**選擇要啟用哪些外掛**，例如 CGM、幫浦、APS 演算法、敏感度偵測、同步等，並依分類整理。這是設定精靈為您設定的同一個畫面。

組態畫面的說明文件請參閱[此處](../SettingUpAaps/ConfigBuilder.md)。

## 設定

點選主畫面右上角的**設定**（齒輪）圖示。這會在同一個地方開啟**所有已啟用外掛的設定**，並分成可展開的區段：

![含有可展開區段的設定畫面](../images/v4/Configuration/settings_overview.png)

如果你不確定在哪裡尋找設定選項，這是一個不錯的方式，但如果你確定只想更改某一特定外掛的設定，那麼過程可能有點繁瑣。

設定的說明文件請參閱[此處](../SettingUpAaps/Preferences.md)。

## 外掛的設定

在**組態**中，開啟某個分類，然後點選已啟用外掛下方的「**設定**」。接著會直接進入**該外掛**的設定：

![已啟用外掛下方的「設定」和「開啟外掛」](../images/v4/Configuration/configuration_open_plugin.png)

例如，如果您知道想要變更幫浦的組態，這個操作方式就很方便：開啟**組態 → 幫浦**，然後點選所選幫浦下方的「**設定**」。

這是前往一般**設定**畫面中相同設定的「捷徑」。
