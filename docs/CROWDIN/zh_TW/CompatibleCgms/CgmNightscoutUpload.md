# 其他上傳至 Nightscout 的 CGM

如果您設定的其他 CGM 可以將血糖資料**僅**傳送至 [Nightscout](https://nightscout.github.io/)，請使用此選項。

```{important}
當你離線、遇到網路問題或你的 Nightscout 網站無法運作時，此資料來源將無法使用。請謹慎使用。
```

-   請在 **NSClientV3**（**組態設定 → 通訊**）中設定 Nightscout 網站資訊。
-   請在 [**組態設定 → 血糖來源**](#Config-Builder-bg-source)中選取 NSClient 血糖。
