# 適合兒童的 AAPS

**AAPS** 也可以成功應用在一型糖尿病的孩子身上。不過，有幾點需要考量。

## 需考慮的事項

### 初始個人設定

對於第一型糖尿病兒童來說，要設定正確的[**設定檔**](../SettingUpAaps/YourAapsProfile.md)（基礎率、ISF、I:C 等）和[胰島素類型](#Config-Builder-insulin-dia)（DIA）可能不容易，尤其是受到生長激素影響時。請花時間測試，確認您對孩子的基礎率、I:C、ISF 和 DIA 都感到滿意。在開始遠端監控和治療之前，請在孩子身邊測試這些設定。週末或學校假期可能是一個不錯的時機。

### 在必要時監控並調整你孩子的個人設定。

隨著孩子的成長，你需要對 **個人設定** 進行調整，以滿足孩子身體的需求。然而，這個問題在所有一型糖尿病的孩子中都是存在的，包括那些使用其他幫浦或注射的孩子。

### 保持手機在範圍內

考慮如何讓孩子的手機保持在他們的幫浦和 **CGM** 的範圍內。對於年齡較小，還無法對手機負責的兒童來說，這可能是一個挑戰。選擇一支藍牙連線範圍良好的 **AAPS** 手機，並找出讓孩子舒適攜帶幫浦和手機的方式。許多解決方案可供選擇，例如有空間放手機的胰島素幫浦腰帶，或者像背包一樣的背帶。

### 如何保護你孩子的 AAPS 免於被濫用？

**AAPS** 提供多種防護設定，可避免孩子或陌生人不當使用 **AAPS**。請參閱[設定 → 防護](#Preferences-protection)，為注射、設定變更，甚至 **AAPS** 本身新增密碼或生物辨識防護。

## 遠端監控和遠端控制

當為孩子使用 **AAPS** 時，遠端監控是一個重要的功能。請參閱專門部分 [遠端監控](../RemoteFeatures/RemoteMonitoring.md) 以探索可能的選項。

遠端監控和治療對於一型糖尿病孩子的父母是非常有益的，尤其是在孩子上幼稚園和小學的時候。但請確保老師和教育工作者了解你孩子的治療計劃。

請規劃如何將遠端控制納入現有計畫，以及它能如何加強現有計畫。許多家長發現，與托育人員另設溝通管道很有幫助，例如準備一支便宜的小型教師「追蹤」手機。

您可以在 Facebook 上的 [AAPS 使用者檔案區](https://www.facebook.com/groups/AndroidAPSUsers/files/)找到學校照護計畫範例。
