# Syai X1


## Používání X1 s aplikací Syai Tag

-   Nainstalujte apk z <https://play.google.com/store/apps/details?id=com.syai.tag>.

-   Spuštění senzoru X1

- Select **Syai/Ottai** in [**Configuration → BG Source**](#Config-Builder-bg-source).

Zapněte vysílání v aplikaci Syai:

1. Vyberte Profile
2. Syai Health Ecosystem
3. Klepněte na Connect Now with AAPS a přijměte dohodu o předávání dat třetí straně
4. Zapněte share data with AAPS
