# Altres CGM enviats a Nightscout

Feu servir aquesta opció si teniu qualsevol altre CGM configurat que pot enviar les vostres dades de glucèmia **només** a [Nightscout](https://nightscout.github.io/).

```{important}
Aquesta font de dades no funcionarà si esteu fora de línia, si teniu problemes de xarxa o si el vostre lloc de Nightscout no funciona. Feu-la servir amb precaució.
```

-   Configureu **NSClientV3** (**Configurador → Comunicació**) amb les dades del vostre lloc de Nightscout.
-   Seleccioneu «Glucèmia NSClient» (NSClient BG) a [**Configurador → Origen glucèmia**](#Config-Builder-bg-source).
