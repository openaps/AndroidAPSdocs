# Where can I get help?

## I'm stuck; what should I do? A qui puc preguntar?

This project is based on volunteer work and a few rules apply to any requests for help to avoid unnecessary time being wasted by those who kindly pay it forward:

* level 1: Read the docs (i.e. this Wiki) - there is now a search function to help you!
* Nivell 2: Cerqueu al grup de Facebook; si encara no hi ha cap resposta, feu la vostra pregunta al [grup de Facebook AndroidAPS Users](https://www.facebook.com/groups/1900195340201874/)
* level 3: If Facebook did not get results then ask in [discord](https://discord.gg/4fQUWHZ4Mw). Les publicacions copiades directament als dos canals s'ignoraran o s'eliminaran a tots dos canals, per evitar respostes duplicades. No oblideu que la majoria dels desenvolupadors són a Europa, per tant la resposta no arriba les 24 hores del dia; potser haureu d'esperar unes quantes hores, sobretot els caps de setmana i els dies festius.
* Nivell 4: Creeu una [incidència (issue)](https://github.com/nightscout/AndroidAPS/issues) i adjunteu-hi els vostres [fitxers de registre](../GettingHelp/AccessingLogFiles.md)
* Nivell 5: correu electrònic a *developers@aaps.app* (només si hi ha dades personals que no s'han de publicar en un canal públic i els vostres problemes no s'han resolt als altres nivells)

For support on CGM sources please use the Facebook groups or Discord channels for that specific system (e.g. [xDrip](https://www.facebook.com/groups/xDripG5/), [600 series uploader](https://www.facebook.com/groups/NightscoutForMedtronic/)) or support on Nightscout use [CGM in the Cloud](https://www.facebook.com/groups/cgminthecloud/) as the users there will have a greater level of expertise than the people here who all use different systems.

## No us oblideu d'unir-vos al grup d'usuaris d'AndroidAPS a Facebook o a Discord!

Uniu-vos al [grup principal d'AndroidAPS a Facebook](https://www.facebook.com/groups/1900195340201874/) i/o a [AndroidAPS a Discord](https://discord.gg/4fQUWHZ4Mw). Aquí podeu publicar qualsevol pregunta sobre l'algoritme, qualsevol problema de configuració que tingueu amb Android Studio i la compilació de l'APK, qualsevol dubte sobre l'ús de l'aplicació i consells per treure-li el màxim profit. També hi ha un grup per als usuaris de la bomba Combo, [AAPSCombo](https://www.facebook.com/groups/127507891261169/), que tenen una configuració una mica més específica.

Please note that Facebook has recently removed external links shared within the **AAPS** Facebook group and this includes current and historic posts which contain external links to the **AAPS** Notes / Read the docs. For new users who are working through the Objectives and reviewing historic **AAPS** Facebook posts please search key terms as discussed within the **AAPS** notes for further assistance.
