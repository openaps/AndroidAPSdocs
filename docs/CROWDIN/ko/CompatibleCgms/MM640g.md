# MM640g 또는 MM630g

-   아직 설정하지 않았다면 [600SeriesAndroidUploader](https://pazaan.github.io/600SeriesAndroidUploader/)를 다운로드하고 [Nightscout](https://nightscout.github.io/uploader/setup/?h=uploader#medtronic-600-series-with-uploader)의 안내를 따르십시오.
-   600 Series Uploader에서 Settings > Send to xDrip으로 이동하여 ON(체크)을 선택하십시오.

![600 series uploader](../images/600Uploader.png)

-   [**구성 → 혈당 출처**](#Config-Builder-bg-source)에서 MM640g를 선택하십시오.
