# Syai X1


## X1과 Syai Tag 앱 사용하기

-   <https://play.google.com/store/apps/details?id=com.syai.tag>에서 apk를 설치하십시오.

-   X1 센서 시작하기

- [**구성 → 혈당 출처**](#Config-Builder-bg-source)에서 **Syai/Ottai**를 선택하십시오.

Syai 앱에서 broadcast를 활성화하십시오:

1. Profile을 선택하십시오
2. Syai Health Ecosystem
3. Connect Now with AAPS를 누르고 제3자 데이터 전송 동의서에 동의하십시오
4. Enable share data with AAPS를 켜십시오
