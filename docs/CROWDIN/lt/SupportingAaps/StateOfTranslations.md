# Programėlės ir dokumentacijos vertimo būsena

The state is once per hour updated and reflects only the state in Crowdin.

```{tip}
Atkreipkite dėmesį: korektūros procentas visada mažesnis už vertimo procentą arba jam lygus, bet Crowdin jį rodo virš vertimo procento.
It's better to look only at the percentage level of translations to see if work is to be done.
```

```{admonition} needed time for final publication
Po vertimo Crowdin kasdien suplanuotas sinchronizavimas su Github: vertimai perkeliami į Github kaip pull request (PR).

PR priimamas rankiniu būdu, kuo greičiau.
```
