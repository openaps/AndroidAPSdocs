# Recursos úteis para ler antes de começar

Antes de montar o seu sistema (rig), você vai precisar ler bastante para entender como tudo funciona e tirar o melhor proveito dele. Reunimos uma lista de lugares onde você pode começar e que, esperamos, respondam a muitas das suas perguntas.
