# Outro CGM enviado ao Nightscout

Use esta opção se você tiver qualquer outro CGM configurado que possa enviar seus dados de glicose **somente** para o [Nightscout](https://nightscout.github.io/).

```{important}
Esta fonte de dados não funciona quando você está off-line, quando há problemas de rede ou quando o seu site do Nightscout está fora do ar. Use com cuidado.
```

-   Configure o **NSClientV3** (**Configuração → Comunicação**) com as informações do seu site do Nightscout.
-   Selecione "Glicemia via NSClient" em [**Configuração → Fonte de BG**](#Config-Builder-bg-source).
