# Change language and version

The documentation you are currently reading is available in several languages and is specific to a given version of **AAPS**. Both the language and the version can be changed from the menu at the bottom right of the screen.

```{note}
Click on the bar at the bottom right of the screen to open the language and version selection menu.
```

![Sprachauswahl öffnen](../images/documentation_language_menu.png)

## Andere Sprache wählen

In the menu, select the language you want to read the documentation in.

Feel welcome to join [Crowdin](https://crowdin.com/project/androidapsdocs) translators and proofreaders to help translate the documentation into your language.

## Version ändern

Die aktuelle Version wird rechts unten auf dem Bildschirm angezeigt. To switch to a different version, click on the current version and select the version you need.

```{warning}
Beim Ändern der Sprache und/oder der Version wirst Du, wenn die Seiten in der entsprechenden Sprache oder Version nicht existieren, eine „404 - Seite nicht gefunden“-Meldung erhalten. Dies geschieht häufig beim Wechsel der Version, sollte aber beim Wechsel der Sprache nicht vorkommen: Wenn die Seiten noch nicht übersetzt sind, werden sie in Englisch angezeigt.
```
