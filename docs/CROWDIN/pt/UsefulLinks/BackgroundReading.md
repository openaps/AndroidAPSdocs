# Recursos úteis para ler antes de começar

Antes de montar o seu sistema, vai ter de ler bastante para perceber como tudo funciona e para tirar o melhor partido dele. Reunimos uma lista de sítios onde pode começar e que, esperamos, respondam a muitas das suas perguntas.
