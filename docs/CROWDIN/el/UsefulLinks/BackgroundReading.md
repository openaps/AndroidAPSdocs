# Χρήσιμοι πόροι για ανάγνωση πριν ξεκινήσετε

Πριν φτιάξετε το σύστημά σας, θα χρειαστεί να διαβάσετε πολύ, για να καταλάβετε πώς λειτουργούν όλα και να έχετε το καλύτερο αποτέλεσμα. Έχουμε συγκεντρώσει μια λίστα με ιστοσελίδες που σας βοηθούν να ξεκινήσετε. Ελπίζουμε ότι θα απαντήσουν σε πολλές από τις ερωτήσεις σας.
