# Otro MCG que sube datos a Nightscout

Usa esta opción si tienes otro MCG configurado que puede enviar tus datos de glucosa **solo** a [Nightscout](https://nightscout.github.io/).

```{important}
Esta fuente de datos no funciona cuando no tienes conexión, cuando hay problemas de red o cuando tu sitio de Nightscout no funciona. Úsala con precaución.
```

-   Configura **NSClientV3** (**Configuración → Comunicación**) con los datos de tu sitio de Nightscout.
-   Selecciona NSClient BG en [**Configuración → Fuente de glucosa**](#Config-Builder-bg-source).
