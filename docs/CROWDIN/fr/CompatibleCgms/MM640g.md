# MM640g ou MM630g

-   Si ce n'est pas déjà fait, téléchargez [600SeriesAndroidUploader](https://pazaan.github.io/600SeriesAndroidUploader/) et suivez les instructions sur [Nightscout](https://nightscout.github.io/uploader/setup/?h=uploader#medtronic-600-series-with-uploader).
-   Dans 600 Series Uploader, allez dans Settings > Send to xDrip et choisissez ON (cochez la case).

![600 series uploader](../images/600Uploader.png)

-   Choisissez Medtronic 640g (MM640g) dans [**Configuration → Source GLY**](#Config-Builder-bg-source).
