The AAPS Builder setup page has moved. It is now maintained by the AAPS developers, together with the build workflow, in the [nightscout/aaps-builder](https://github.com/nightscout/aaps-builder) repository.

**→ <a href="https://nightscout.github.io/aaps-builder/" target="_blank" rel="noopener">Open the AAPS Builder setup page</a>** (nightscout.github.io/aaps-builder)

Each step of the setup page is explained, with screenshots, in [Browser build with AAPS Builder](#aaps-builder).

Your repository was set up with the setup page of this documentation? It keeps working. To use the new version, replace your workflow file once, as explained in [Updating AAPS](#aaps-builder-updates). Your `KEYSTORE_SET` secret stays as it is.
